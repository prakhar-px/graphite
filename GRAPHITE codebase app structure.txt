1. Overall Project Structure
Graphite is a Next.js 16 (App Router) + TypeScript private project serving as a FAANG DSA (Data Structures & Algorithms) interview preparation dashboard -- a "Mission Control" for tracking a 70-day structured study plan.

Stack: Next.js 16.2.6 (App Router), React 19, TypeScript 5, Tailwind CSS 4, Zustand (localStorage), Recharts, Framer Motion, shadcn/ui, date-fns.

Summary
This is a well-structured Next.js 16 App Router project serving as a FAANG DSA interview preparation dashboard ("Mission Control"). Key architecture patterns:

Excel-driven data: All roadmap data (70-day plan, dashboard metrics, revision tracker, company prep, mistake log, weekly reviews) is parsed from Excel workbooks into JSON via scripts/parse-excel.ts
Engine architecture: Business logic is organized into domain-specific "engines" (planner, telemetry, analytics, problems, revision, topics, confidence, dashboard, ai) in src/engines/
Telemetry system: Problem-solving data flows from manual logging or LeetCode sync through ProblemLog entries stored in Zustand (localStorage), then computed through engines/telemetry/selectors.ts and related engines
Zustand state management: src/store/app-store.ts persists day statuses, problem logs, and user preferences to localStorage
AI Coach integration: Gemini API-powered coach accessible via /api/ai/coach route, using telemetry data as context
LeetCode integration: Full sync pipeline with GraphQL API queries, submission deduplication, and bulk import
